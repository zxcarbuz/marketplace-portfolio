# DXRK — портфолио дизайнера маркетплейсов

Сайт: https://zxcarbuz.github.io/marketplace-portfolio/

Адаптивный статический сайт без обязательных платных сервисов, ИИ API, сборщика, аналитики, cookies и внешних шрифтов. Шесть SVG-иллюстраций созданы для проекта. Представлены как демонстрационные концепты; связь с реальными брендами не заявляется.

## Файлы

- `index.html` — структура, тексты, метаданные SEO, контактные ссылки.
- `styles.css` — цвета, типографика, адаптивность, анимация и режим reduced motion.
- `config.js` — тарифы, Telegram username и чистая функция расчёта.
- `order.js` — текст заявки и безопасное кодирование ссылки Telegram.
- `app.js` — галерея, фильтры, карусель, модальное окно, конструктор.
- `assets/` — оригинальные SVG-карточки и favicon.
- `tests/pricing.test.js` — проверки расчёта, границ и кодирования заявки.

## Управление с телефона через GitHub

1. Откройте нужный файл в репозитории → карандаш Edit.
2. Внесите изменение → Commit changes. Используйте понятное описание.
3. После завершения Pages deployment проверьте публичный сайт. Если видна старая версия, перезагрузите страницу.
4. Для отката откройте историю файла и восстановите содержимое предыдущей версии отдельным коммитом.

### Изменить цены

Измените `config.js`, объект `prices`. Обложка оплачивается один раз; `slide` — каждый слайд после обложки; надбавка стиля — один раз за товар; допуслуги — за серию одного товара; срочность умножает всю сумму.

Синхронизируйте также видимые подписи тарифов в `index.html`: три услуги, три варианта стиля, четыре допуслуги. Эти HTML-подписи доступны даже без JavaScript. Контрольные суммы в тестах нужно обновить при смене тарифов.

Текущие предварительные тарифы: обложка 1200 ₽; дополнительный слайд 600 ₽; яркий стиль +300 ₽; премиальный +500 ₽; ретушь +500 ₽; тексты +400 ₽; адаптация +600 ₽; срочность +50%. Обязательные платежи третьим лицам отсутствуют.

### Изменить Telegram

В `config.js` замените `telegram` (без @). В `index.html` замените все ссылки `https://t.me/dxrkchxosoff` и подписи контакта. Номер телефона не нужен.

### Заменить работы

1. Добавьте своё изображение в `assets/` с коротким латинским именем.
2. В начале `app.js` измените массив `works`: `id`, название, категорию, описание и `alt`.
3. Текущая реализация ожидает `assets/<id>.svg`. Для JPEG/WebP измените генерацию путей в двух местах `app.js` и размеры при необходимости.
4. Для фото используйте WebP, ограничьте размер по длинной стороне примерно 1600 px. Не удаляйте width/height: они уменьшают скачки вёрстки.
5. При смене двух работ первого экрана обновите их пути в `index.html`.
6. Реальные кейсы добавляйте с разрешения клиента; подпись о демонстрационных работах уточняйте по мере появления реальных.

### SEO

Отредактируйте `title`, `description`, `og:title`, `og:description`. Публичные `canonical`, `og:url` и `og:image` настроены. При смене адреса обновите их; изображение превью — `assets/og-image.jpg`. Заголовки и описания изображений должны оставаться содержательными.

## Бесплатная архитектура заявок

Браузер рассчитывает цену → формирует текст → открывает `https://t.me/<username>?text=<URL-encoded draft>` → клиент проверяет и самостоятельно нажимает отправку в Telegram.

Спецификация: https://core.telegram.org/api/links#public-username-links

Нет токена бота, сервера, ИИ API или базы заявок. Отправка не происходит автоматически. Если Telegram-клиент не поддерживает черновик, предусмотрено копирование, а при отказе Clipboard API — поле для ручного копирования. Текст заявки передаётся Telegram при открытии ссылки; не просите вводить секреты или платёжные данные.

Возможное расширение: Bot API через серверный обработчик с токеном только в secrets, проверкой входных данных, защитой от спама и лимитами. Бесплатные серверные тарифы имеют квоты, поэтому не используются как обязательная зависимость. Никогда не добавляйте токен в JS, HTML или историю Git.

## Запуск и проверки

Node.js 20+ для тестов; зависимости устанавливать не нужно:

```sh
npm test
```

Локальный просмотр (ES modules требуют HTTP, двойной клик на HTML не подходит):

```sh
python3 -m http.server 8080
```

Откройте `http://localhost:8080`. Проверьте сетку/карусель, все фильтры, модальное окно, Esc и стрелки, переходы Tab, 1 и 20 слайдов, допуслуги, Telegram и копирование. Для телефона используйте адаптивный режим браузера. Реальное устройство iOS/Android дополнительно проверить после публикации.

## Публикация на GitHub Pages

1. Создать отдельный публичный репозиторий `marketplace-portfolio`.
2. Загрузить отслеживаемые файлы в ветку `main`, сохранив историю коммитов.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save.
4. Дождаться успешного `pages build and deployment`, открыть адрес из Settings → Pages.
5. Проверить страницу и загрузку `app.js`, `order.js`, `config.js`, `styles.css` и шести изображений. Все пути относительные, сайт работает в подпапке репозитория.

Файл `.nojekyll` отключает ненужную обработку Jekyll. Секреты не требуются. Не публиковать `.env`, служебный `dist/`, локальные материалы с персональными данными. Файлы `.gitignore` исключают служебные данные.

## Ограничения

- Калькулятор оценивает один товар, не выставляет счёт и не принимает оплату.
- Нет автоматической доставки заявки и отчёта о её получении.
- Тарифы предварительные: перед публичным коммерческим использованием владелец может скорректировать их.
- SVG-концепты демонстрируют композицию и иллюстрацию; это не фотографии реальных товаров.
